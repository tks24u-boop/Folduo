# 設計ノート：TŌGE（峠）の寸法の決め方と検証結果

数値の正本は `src/clamshell_dock.py` の `P` クラスです。調査の内容は[リサーチ](research.md)にあります。

## 0. これまでの版と、この版の決め方

| | 1版（2026-09-28） | 2版（09-29） | 3版 TŌGE（この版） |
|---|---|---|---|
| 形 | 200×116×46 mmの塊 | 180×104×34 mm、薄い板＋細い立ち上がり | 200×138×66 mm、低い峠と2つの峰 |
| 材料 | PLA＋TPU | PLA＋フェルト | 黒PETG＋蓄光PLAのバッジ＋フェルト |
| 刷るファイル | 3（全体36） | 2 | 2＋任意のゲージ |
| 本体 | 252 g／約4時間 | 95 g／約2時間 | 211 g／約7時間 |
| Macの差し方 | ヒンジ上 | ヒンジ上 | ヒンジ下 |
| 倒れ始める力（Air 13） | 3.0 N | 2.9 N | 4.2 N |
| ケーブル | T字の溝 | なし | 両端の後ろに押し込む溝 |

3版は次の順で決めました。
1. 市販品・国内製品・3Dプリント作例・Air M5の仕様・素材・造形の考え方の7つの観点で、口コミと資料を調べ直した（[リサーチ](research.md)の「再調査」）。
2. 観点の違う5案を作り、デザイン・製造・使う人の立場の3人で採点した。一番点の高かった「アウトリガー」案を土台にして、ほかの案の良いところを取り込んだ。
3. 作ったモデルを、6つの観点（はまり具合、印刷、コード、倒れにくさと強度、デザイン、日々の使い勝手）で別々にレビューし、確かめられた指摘を直した（10章）。

## 1. 形：峠と富士

- 断面は1本の閉じた輪郭（22辺）で、x（Macの幅方向）に沿って形が変わります。中央の84 mm（|x| ≤ 42）は同じ断面、両端の20 mm（80 ≤ |x| ≤ 100）も同じ断面で、その間を19断面でロフトしています。断面は両端の近くほど細かく置き、ロフトの曲面が補間式から0.01 mm以内に収まることを `check_fit.py` で確かめています（はじめの10断面では、x = 42 mmのすぐ外で峰の線が0.4 mmへこんでいました）。
- すべての寸法は、同じ5次の補間式 s = 6t⁵ − 15t⁴ + 10t³ で中央から端へ移ります。峰の高さ（24→66 mm）、裾の広がり（74→138 mm）、斜面の角度（45°→ふもと20°・頂上80°）、溝の壁の位置が同時に動くので、継ぎ目のない一つの形になります。
- 端面は切りっぱなしにして、富士山形の断面とスロットを見せます。輪郭は1 mmの面取りでなぞってあります。
- 丸と面取りの使い分け：Macや指が滑る場所（入口のラッパ、峰の頂、裾の先）は丸め、目で見る輪郭（端面、底の縁）は面取りにしました。
- 底は裾の下で45°に切れ込み（3 mm→0.6 mm）、ゴム脚で1.2 mm浮いています。机との間に細い影ができ、置いた物が浮いて見えます。

## 2. Macの持ち方

| 部分 | 寸法 | ねらい |
|---|---|---|
| V溝 | 45°の2面。フェルト2 mmを0.4 mmのくぼみに貼り、1.6 mm出す | ヒンジ側の角2本がフェルトに載り、印刷の誤差に関係なく中央にすき間なく座る |
| Macの下端 | 机から8.1 mm（フェルトが斜面に垂直に0.3 mmへたる分を含む） | 溝の底（高さ4.6 mm）から3.5 mm浮く |
| V溝のフェルトの幅 | 6 mm。Macの角はその縁から2.5 mm内側に載る | 角がフェルトの縁に載ってめくらない |
| 入口 | どこでも幅31 mm。ラッパ形（2次ベジェ） | 上から下ろすだけで中央へ導かれ、角に当たらない |
| 峰の溝の壁 | 中央は±12 mm（Macから6.35 mm）、峰は±7.75 mm（Macから2.1 mm） | 中央は熱のために開け、峰でだけ支える |
| パッド | 峰の内側に4か所、13×9 mm、高さ45〜54 mm | 押されたときだけ触れる。V溝の当たりとの高さの差は約41 mm |
| パッドの間 | 11.9 mm（Air 11.3 mm＋すき間0.6 mm） | 挟まない。上端の揺れは全体で3 mm以内 |

- 何も挟んでいないので、真上に持ち上げた瞬間にMacはV溝から離れます。フェルトを押しつぶして挟むと、2 mmのフェルトなら数十Nで挟むことになり、軽いドックはMacと一緒に持ち上がります（リサーチの落とし穴）。
- 例外は、大きく傾けながら抜く場合です。Macの上端を横に引くと、テコの比（Macの高さ215 mm÷パッドの高さ41 mm ≒ 5）でパッドを押します。10°傾けただけで、パッドには約10 Nかかります。フェルトの摩擦係数を0.3〜0.5とすると摩擦は3〜5 Nになり、ドックの重さ（2.1 N）を超えます。READMEには真上に抜くように書きました。気になる人のために、パッドを滑るテープにする版（`--liner`）も用意しました。
- パッドを載せる台（ランド）は、溝の壁から滑らかなS字の斜面で立ち上がります。下側の斜面は、パッドをずらした場合も45°より急にならないよう、長さを自動で伸ばします。
- パッドのくぼみの天井は45°なので、橋渡しなしで刷れます。パッドの表面は、くぼみの縁より0.5 mm手前に出ています。Macがフェルトのめくれた縁や台の角に当たらないようにするためです。
- 本当のヒンジ側の角の丸みはAppleが公表していません。モデルでは両側R2.5にしています。天板側と底側で丸みが違うと、Macがわずかに片側へ寄ります。ゲージの試し片で確かめ、寄っていたら `--v-offset` でパッドの位置をずらします。

## 3. 倒れにくさ

Macとドックをひとつの剛体とみなして、静的に計算しました。
- 支点は、ゴム脚の外側の縁（中心から66.5 mm）です。
- ドックの重さは0.216 kg（本体211 g＋バッジ・フェルト・脚）です。

| 項目 | 値 | 式 |
|---|---|---|
| Macの上端を横に押して傾き始める力 | 4.23 N（約430 gf） | (m_Mac + m_dock)·g·b / h_top |
| 傾けて倒れる角度 | 33° | atan(b / 重心の高さ) |
| 地震で倒れ始める加速度（静的） | 0.66 g | b / 重心の高さ |
| ケーブル溝の高さ（8 mm）で横に引いたとき | 118 N | (m_Mac + m_dock)·g·b / 8 |

- 倒れにくさはほとんど裾の広さで決まります。裾の半幅を10 mm広げると約0.6 N増えますが、おもりを100 g足しても約0.2 Nしか増えません。そのため、おもりは使わずフィラメントだけで出しました。
- 充填を15%にすると4.18 N、25%にすると4.27 Nです。
- ケーブルを引っかけた場合：ヒンジ下ではポートが机から約28〜58 mmの高さにあります。ケーブルを溝に通さなくても、倒すには16〜34 Nかかります。一方、滑らせるのに必要な力は11〜20 Nなので、倒れる前にドックが滑ります（机との摩擦係数0.8〜1.4の場合）。溝に通せば、倒すのに118 Nかかります。
- 2版まではヒンジ上に差していたので、ポートが高さ170〜200 mmにあり、3〜4 Nの引っかけで倒れる計算でした。これがヒンジ下に変えた一番の理由です。
- 2版の数値は脚の縁を支点にしたものでした。1版は本体の縁を支点にしていたため、実際より良く出ていました（同じ条件で比べると24.3°・3.0 N）。

## 4. ケーブル

- 両端の後ろ側に、USB-C／Thunderbolt用（穴Ø5.3、入口幅4.2 mm）とMagSafe用（穴Ø3.9、入口幅3.0 mm）の溝があります。
  - 溝の中心は、前後の中心からそれぞれ24.5 mmと33.5 mmです。
  - 裾の先から離してあるので、裾の先が薄い刃のようになりません。
- 溝は底に開いていて、ケーブルを下から押し込みます。入口にはすぼまった口があり、押し込むと抜けにくくなります。入口より細いケーブルはそのまま溝に収まり、置いたドックの下で机が押さえます。
- 入口が狭すぎた場合は、カッターで削って広げられます。そのため、入口の幅はゲージで試さないことにしました。
- 溝は端面からまっすぐ12 mm入り、そこから後ろへ曲がって裾から出ます。曲げ半径はUSB-Cが51.5 mm（TB4ケーブルの最小曲げ半径は48 mm）、MagSafeが42.5 mmです。
- 天井は45°の屋根形なので、橋渡しなしで刷れます。
- 端面には、プラグの置き場のくぼみがあります（USB-C 7.8×13.4 mm、MagSafe 4.9×13.6 mm、深さ2 mm）。Macから抜いたプラグを、挿すときと同じ縦向きで差しておけます。
- 磁石は使っていません。MacBookのふたの開閉センサーは磁石に反応するためです。

## 5. 熱

- 実測はありません。以下は計算と公開データからの見積もりです。
- Notebookcheckの測定では、M5のAirは負荷をかけるとヒンジ側の半分が40〜44 °C、手前側が30〜33 °Cになります。
- ヒンジを下にすると、熱い側がドックの中に入ります。それでも次の工夫で影響を小さくしました。
  - Macに触れるのは、V溝のフェルトがヒンジ側の角に当たる2本の線だけです。
  - 中央の84 mmは、溝の壁をMacから6.35 mm離しています。
  - 峰の部分でも、パッド以外はMacから2.1 mm離れています。
  - Macの正面（平らな部分）のうち、3 mm以内にPETGがあるのは5.9%だけです。2版はフェルトの壁が8%を覆っていました。
- 自然対流の理屈では、熱い側が下にあるほうが冷えやすくなります（下のほうが空気の流れが速い）。ただし放射もあるので差は小さく、ヒンジ上との差は±2 °Cの範囲と見ています。
- 印刷したPETGやPLAは熱をほとんど通しません（約0.2 W/m·K）。ドックがMacを冷やすことはないので、冷却効果はうたいません。
- 材料の余裕：PETGの荷重たわみ温度は62〜68 °Cです。夏（室温30〜35 °C）の負荷時にヒンジ側が45〜53 °Cになっても、10〜20 °Cの余裕があります。PLAは55 °C前後で柔らかくなるので、荷重のかかる部分とMacに近い部分には使っていません（バッジはMacから13 mm）。
- M5のAirは、ふたを開けたままでも外部ディスプレイを2台つなげます。重い処理を長く続けるときは、開けて使う選択肢もあります。

## 6. Clawdのバッジと蓄光

- ピクセル配置は、Claude Code CLI（npm `@anthropic-ai/claude-code` 2.0.77）の起動画面のブロック文字を、そのまま2×2の区画に分けたものです。1ピクセルは幅2 mm×高さ4 mmで、全体は32×20 mmです。
- 置き場所は、中央の低い部分の45°の正面です。座った目線に対して正面を向き、Macのヒンジのすぐ手前にあります。
- バッジは厚さ3 mmで、表から2 mmが蓄光PLA、奥の1 mmが白PLAです。
  - 蓄光の明るさは、厚さ2 mmくらいまで増え、それ以上はほとんど変わりません（CNC Kitchenの測定）。
  - 奥の白が光を前へ返します。
  - 中まで充填100%で刷ります。充填のすき間があると蓄光の厚みが足りず、光り方にむらが出るためです。
- 目は、本体から立ち上がる黒PETGのピン（2×4 mm）です。バッジの目の穴を通って表に出るので、黒い目になります。
  - 同時に、このピンがバッジを留めています。PLAとPETGはほとんど接着しないので、接着剤ではなく形で留めています。
  - すき間はバッジの側に持たせました。目の穴は片側0.10 mm大きく（`--pin-clr`）、外形は片側0.15 mm小さく（`--badge-clr`）してあります。
  - 本体のくぼみとピンは図面どおりの寸法です。固すぎたり緩すぎたりしても、刷り直すのは5分のバッジだけで済みます。
  - 45°の面から立つピンは、下向きの面が少し垂れて太めに出ます。既定のすき間は、それを見込んだ値です。
  - 外すときは、底の穴（Ø2.5）から押し出します。穴はくぼみの床まで完全に抜けています。
- バッジのくぼみの壁はすべて45°か垂直なので、橋渡しなしで刷れます。
- 蓄光は2時間ほどで最初の1割ほどの明るさになります。それでも暗さに慣れた目には見え、夜にドックの位置の目印になります。

## 7. 材料の分け方

| 部分 | 材料 | 理由 |
|---|---|---|
| 本体（荷重を受ける・Macに近い） | 黒PETG | 荷重たわみ温度62〜68 °C。PLAは45 °Cでクリープする |
| バッジ | 蓄光PLA＋白PLA | 同じPLA同士なので層がくっつく。荷重はかからない |
| Macに触れる部分 | フェルト | 金属や硬い樹脂を当てない（Appleの寸法図の注意書き：NO METAL CONTACT） |
| 脚 | 平らなゴム脚 | 滑りにくい。くぼみに入れて横にずれないようにする |

## 8. 印刷性

| 項目 | 結果 |
|---|---|
| メッシュ | 本体・バッジ・ゲージとも1つの閉じたソリッド（STLを読み直して確認） |
| スライス | PrusaSlicer 2.7にP2S相当の速度・加速度を設定し、3つともエラーなし |
| 本体 | 0.20 mm・壁5・ジャイロイド20%で211 g・6時間56分 |
| ゲージ | 22 g・45分（試し片と櫛） |
| バッジ | 1.7 g・5分（色替えの時間は含まない） |
| 45°より急な下向きの面 | 脚のくぼみの天井（483 mm²）とプラグ置き場の天井（51 mm²、奥行2 mm）だけで、どちらも短い橋渡し。ほかはロフトのメッシュの面が最大48°になる程度。サポートは不要 |

- 3MFには、Bambu Studioが読むオブジェクトごとの設定（`Metadata/model_settings.config`）を入れてあります。
  - 本体とゲージ：壁ループ5、充填20%のジャイロイド、継ぎ目は奥
  - バッジ：充填100%、パーツごとのフィラメント（蓄光＝1、白＝2）
  - Bambu Studioのソース（`bbs_3mf.cpp`）で、他社製3MFでもこのファイルを読むことを確かめてあります。
- 継ぎ目を奥に集めると、前半分の島は継ぎ目が溝の内側に、後ろ半分の島は後ろの面に並びます。どちらも正面からは見えません。
- 前の版でPrusaSlicerが出していた「ベッドへの付着が弱い」という警告は、ケーブルの溝を裾の先から内側へ移したあとは出なくなりました。
- 高さ4.6 mmより上では、前後の2つの島に分かれて刷られます。溝をまたぐ移動で糸を引くことがあるので、フェルトを貼る前に溝の中を掃除してください。
- ゲージは、本体を刷り直さないと直せないもの（Macのはまり具合）だけを試します。
  - はじめは、バッジのはまり具合とケーブルの入口を試す小片も入れていましたが、それだけで60 g・3時間41分になりました。
  - そこで、バッジは自分の側にすき間を持たせ、入口は削って広げられることにして、小片をやめました。

## 9. まだ確かめていないこと

- 実際の印刷と、実物のMacBook Air 13（M5）でのはまり具合。とくにヒンジ側の角の形。
- 実物のフェルトの厚さ（±0.2 mm）と、45°の面に貼ったときの粘着の持ち。
- 倒れにくさ・持ち上げ・排熱の実測（READMEの「実物での確かめ方」）。
- Bambu Studioで開いた結果。コンテナにインストールできなかったため、ソースコード（`bbs_3mf.cpp`）を読んで確認しました。他社製3MFの「1オブジェクト＋複数コンポーネント」は、1つのオブジェクトの複数パーツとして読み込まれます。

## 10. レビューで直したこと

モデルができたあと、観点ごとに別のレビュアーが、実際にモデルを作り直したり、測ったり、スライスしたりして確かめました。直した主な点は次のとおりです。

| 指摘 | 直し方 |
|---|---|
| ゲージの櫛の溝が重なっていて、歯がなかった | 溝の間隔をパッドのくぼみ込みで決め直し、歯は最低4 mm。`check_fit.py` で歯の厚さを検査する |
| 櫛の溝の前がふさがっていて、Macの縁に沿って滑らせられなかった | 前後と上に抜けた溝にし、底でつなぐ |
| `--v-offset` を0.6 mm以上にすると、パッドの台が壁から浮いた | 台を壁の中まで根を張る形にし、ソリッドが1つであることを毎回確かめる |
| `--mac-t` で厚さを変えても、溝の壁が動かなかった | 壁の位置をMacからのすき間で決める。無理な組み合わせはエラーで止める |
| Macの座る高さの計算で、フェルトのへたりを縦に足していた | 斜面に垂直なへたりとして√2倍で扱う（8.25→8.12 mm） |
| 45°の面から立つ目のピンがきつすぎた | すき間を片側0.10 mmにし、すき間をバッジの側に移した |
| バッジの中が充填のすき間になると、光り方にむらが出る | 3MFに充填100%を入れた |
| ケーブルの溝とプラグ置き場で裾の先が薄い刃になり、PrusaSlicerが付着の警告を出した | 溝を内側（24.5 mmと33.5 mm）へ移した |
| パッドのくぼみの天井が水平の張り出しだった | 天井を45°にした |
| 押し出し用の穴の上が、くぼみの床で一部ふさがっていた | 穴を床の最も高い所まで通す |
| パッドの台の縁が角ばっていて、端の面取りとぶつかっていた | 台の上下をS字の斜面にし、長さを81.5〜97 mmにして面取りから離した |
| 傾けて抜くと、パッドのフェルトの摩擦でドックが浮く | フェルトのまま、READMEに真上に抜くことと確かめ方を書き、滑るテープの版（`--liner`）を用意した |
| Macの角がV溝のフェルトの縁に載っていた | フェルトのくぼみを斜面の上へずらし、角が縁から2.5 mm内側に載るようにした |
| 検査が本当は何も確かめていない項目があった | `check_fit.py` を作り直し、落ちた検査の名前を出して止まるようにした。作り直しのオプションをそのまま受け取る |
