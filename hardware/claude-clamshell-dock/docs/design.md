# 設計ノート：TŌGE（峠）の寸法の決め方と検証結果

数値の正本は `src/clamshell_dock.py` の `P` クラスです。調査の内容は[リサーチ](research.md)にあります。

## 0. これまでの版と、この版の決め方

| | 1版（2026-09-28） | 2版（09-29） | 3版 TŌGE（この版） |
|---|---|---|---|
| 形 | 200×116×46 mmの塊 | 180×104×34 mm、薄い板＋細い立ち上がり | 199×138×60 mm、低い峠と2つの峰 |
| 材料 | PLA＋TPU | PLA＋フェルト | 黒PETG＋蓄光PLAのバッジ＋フェルト |
| 刷るファイル | 3（全体36） | 2 | 2＋任意のゲージ |
| 本体 | 252 g／約4時間 | 95 g／約2時間 | 185 g／約7.5時間（0.16 mm） |
| Macの差し方 | ヒンジ上 | ヒンジ上 | ヒンジ下 |
| 倒れる力（脚の外縁が支点、Air 13） | 3.0 N | 2.9 N | 4.0 N |
| 奥の脚が浮き始める力（3章の計算） | — | 約2.4 N | 3.7 N |
| ケーブル | T字の溝 | なし | 右端の後ろに押し込む溝 |

3版は次の順で決めました。
1. 市販品・国内製品・3Dプリント作例・Air M5の仕様・素材・造形の考え方の7つの観点で、口コミと資料を調べ直した（[リサーチ](research.md)の「再調査」）。
2. 観点の違う5案を作り、デザイン・製造・使う人の立場の3人で採点した。一番点の高かった「アウトリガー」案を土台にして、ほかの案の良いところを取り込んだ。
3. 作ったモデルを、6つの観点（はまり具合、印刷、コード、倒れにくさと強度、デザイン、日々の使い勝手）で別々にレビューし、確かめられた指摘を直した（10章）。

## 1. 形：峠と富士

- 断面は1本の閉じた輪郭（22辺）で、x（Macの幅方向）に沿って形が変わります。
  - 中央の84 mm（|x| ≤ 42）は同じ断面、両端の20 mm（80 ≤ |x| ≤ 100）も同じ断面です。
  - その間は19断面でロフトしています。断面は両端の近くほど細かく置きました。ロフトの曲面が補間式から0.01 mm以内に収まることを、`check_fit.py` で確かめています。
  - はじめの10断面では、x = 42 mmのすぐ外で峰の線が0.4 mmへこんでいました。0.2 mmの層なら2〜3層の段になり、峠から峰へ目で追う線がそこで折れて見えます。
- すべての寸法は、同じ5次の補間式 s = 6t⁵ − 15t⁴ + 10t³ で中央から端へ移ります。峰の高さ（24→60 mm）、裾の広がり（74→138 mm）、斜面の角度（45°→ふもと20°・頂上80°）、溝の壁の位置が同時に動くので、継ぎ目のない一つの形になります。
- 端面は、下の縁を軸に7°内側へ傾けました。正面から見ると峰が台形にすぼまり、四角い柱のようには見えません。
  - 輪郭は1.5 mmの面取りでなぞってあります。
  - 左端（Appleのマークを手前にしたとき、ケーブルを使わない側）は、何も切らない富士山形の断面のままです。
- 丸と面取りの使い分け：Macや指が滑る場所（入口のラッパ、峰の頂、裾の先）は丸め、目で見る輪郭（端面、底の縁）は面取りにしました。
- 底は裾の下で45°に切れ込み（3 mm→0.6 mm）、ゴム脚で1.2 mm浮いています。机との間に細い影ができ、置いた物が浮いて見えます。
- 見た目の量感：座った目線で見えるドックの面積は、「太すぎる」と言われた1版の約86%でした。峰を66→60 mmに下げ、端面を傾けて、そこから約9%減らしました。これ以上減らすには裾を狭めるしかなく、倒れにくさと引き換えになります。裾の半幅を69→60 mmにすると2版並みの量感になりますが、倒れる力は約3.6 Nに下がります（デザインのレビューの試算）。

## 2. Macの持ち方

| 部分 | 寸法 | ねらい |
|---|---|---|
| V溝 | 45°の2面。フェルト2 mmを0.4 mmのくぼみに貼り、1.6 mm出す | ヒンジ側の角2本がフェルトに載り、印刷の誤差に関係なく中央にすき間なく座る |
| Macの下端 | 机から9.6 mm（フェルトが斜面に垂直に0.3 mmへたる分を含む） | 溝の底（高さ6.1 mm）から3.5 mm浮く |
| V溝のフェルトの幅 | 6 mm。Macの角はその縁から2.5 mm内側に載る | 角がフェルトの縁に載ってめくらない |
| V溝の下の厚み | 4.9 mm | 下の「たわみ」を参照 |
| 入口 | どこでも幅31 mm。ラッパ形（2次ベジェ） | 上から下ろすだけで中央へ導かれ、角に当たらない |
| 峰の溝の壁 | 中央は±12 mm（Macから6.35 mm）、峰は±7.75 mm（Macから2.1 mm） | 中央は熱のために開け、峰でだけ支える |
| パッド | 峰の内側に4か所、10.5×9 mm、高さ39〜48 mm | 押されたときだけ触れる。V溝の当たりとの高さの差は33 mm |
| パッドの間 | Macを載せた状態で11.9 mm（Air 11.3 mm＋すき間0.6 mm）。空のときは12.0 mm | 挟まない。上端の揺れは全体で約4 mm |

- 何も挟んでいないので、真上に持ち上げた瞬間にMacはV溝から離れます。フェルトを押しつぶして挟むと、2 mmのフェルトなら数十Nで挟むことになり、軽いドックはMacと一緒に持ち上がります（リサーチの落とし穴）。
- 例外は、傾けながら抜く場合です。Macの上端を横に引くと、テコの比（Macの上端までの高さ÷パッドの高さ ≒ 6.5）でパッドを押します。
  - 倒れにくさのレビューの計算では、使い込んだフェルトなら、垂直から約5°傾けて片手で抜くだけでドックが浮きます（横向きの力1.2 N）。
  - 抜きはじめて3 mmほど上がると、Macの下の縁がパッドのない溝の壁（PETG）に当たります。そこから先は、3°以上傾いていれば1 N足らずで浮きます。
  - READMEには真上に抜くように書き、確かめ方に「5°傾けて抜く」を入れました。気になる人のために、パッドを滑るテープにする版（`--liner`）も用意しました。
- たわみ：脚は裾の先にあり、Macの重さは中央のV溝にかかります。そのため本体は、V溝の下を蝶番にして、前後の半分がわずかに内へ倒れます。
  - レビューの有限要素法の計算では、厚み3.4 mmのままだと、Macの重さだけでパッドのすき間が合計0.2 mm閉じました。
  - V溝ごと1.5 mm上げて厚みを4.9 mmにし、閉じる量をおよそ半分にしました。
  - 残りの片側0.05 mmは、パッドを最初から外へ出して打ち消しています。
  - それでも峰を両側からつまむと、10〜15 NでMacを挟みます。両手で抜くときは、峰ではなく裾（脚の上）を押さえてください。
- パッドを載せる台（ランド）は、溝の壁から滑らかなS字の斜面で立ち上がります。下側の斜面は、パッドをずらした場合も45°より急にならないよう、長さを自動で伸ばします。
- パッドのくぼみの天井は45°なので、橋渡しなしで刷れます。パッドの表面は、くぼみの縁より0.5 mm手前に出ています。Macがフェルトのめくれた縁や台の角に当たらないようにするためです。
- 本当のヒンジ側の角の丸みはAppleが公表していません。モデルでは両側R2.5にしています。天板側と底側で丸みが違うと、Macがわずかに片側へ寄ります。ゲージの試し片で確かめ、寄っていたら `--v-offset` でパッドの位置をずらします。

## 3. 倒れにくさ

Macとドックをひとつの剛体とみなして、静的に計算しました。
- ドックの重さは0.19 kg（本体185 g＋バッジ・フェルト・脚）です。
- 平らなゴム脚は、傾くまで面全体で均等に押します。そのため、奥の脚が浮き始めるのは、力のモーメントが脚の**中心**（y = 61 mm）に届いたときです。
- 倒れるのは、少し揺れて手前の脚の**外縁**（66.5 mm）に支点が移ってからです。
- Macがパッドのすき間とフェルトの分だけ傾くと、重心が支点側へ寄ります。その分（約0.1 N）を差し引きました。

| 項目 | 値 | 式 |
|---|---|---|
| Macの上端を横に押して、奥の脚が浮き始める力 | 3.7 N（約375 gf） | (m_Mac + m_dock)·g·y_脚中心 / h_top − 傾きの分 |
| 同じく、倒れる力 | 4.0 N（約410 gf） | 支点を脚の外縁にして同じ式 |
| 傾けて脚が浮き始める角度 | 30.5° | atan(y_脚中心 / 重心の高さ) |
| 地震で脚が浮き始める加速度（静的） | 0.59 g | y_脚中心 / 重心の高さ |
| ケーブル溝の高さ（8 mm）で横に引いたとき | 106 N | (m_Mac + m_dock)·g·y_脚中心 / 8 |

- 前の版の計算は、支点を脚の外縁に置いていたので、実際より良く出ていました。表の0章では、同じ式の値（倒れる力）と、この章の新しい値を並べています。
- 倒れにくさはほとんど裾の広さで決まります。裾の半幅を10 mm広げると約0.6 N増えますが、おもりを100 g足しても約0.2 Nしか増えません。そのため、おもりは使わずフィラメントだけで出しました。
- 充填を15%にしても、浮き始める力は3.66 Nとほとんど変わりません。
- 裾の先に細いゴムの帯（15×4 mm）を貼れば、脚の中心が外へ出て、浮き始める力は約4.0 Nまで上がります。今回は手持ちの丸いゴム脚を使うことを優先しました。
- ケーブルを引っかけた場合（レビューで、机の上での回転も含めて計算）：
  - ヒンジ下ではポートが机から約28〜58 mmの高さにあります。横に引くと、ドックは3〜10 Nで回るか滑ります。倒すには15〜31 Nかかるので、先に回るか滑ります。
  - 溝に通したケーブルなら、倒すのに106 Nかかります。
- 2版まではヒンジ上に差していたので、ポートが高さ170〜200 mmにあり、3〜4 Nの引っかけで倒れる計算でした。これがヒンジ下に変えた一番の理由です。
- 空のドックは重心が低く（約18 mm）、70°以上傾けるまで倒れません。

## 4. ケーブル

- 右端の後ろ側に、USB-C／Thunderbolt用（穴Ø5.3、入口幅4.2 mm）とMagSafe用（穴Ø3.9、入口幅3.0 mm）の溝があります。
  - 溝の中心は、前後の中心からそれぞれ23 mmと32 mmです。
  - 右端にだけあるのは、Appleのマークを手前にするとポートが右に来るからです。左端は何も切らない断面のままにしました。逆向きに使う場合は `--cables left` で作り直します。
- 溝は底に開いていて、ケーブルを下から押し込みます。入口にはすぼまった口があり、押し込むと抜けにくくなります。入口より細いケーブルはそのまま溝に収まり、置いたドックの下で机が押さえます。
- 入口が狭すぎた場合は、カッターで削って広げられます。そのため、入口の幅はゲージで試さないことにしました。
- 溝は端面からまっすぐ12 mm入り、そこから後ろへ曲がって裾から出ます。曲げ半径はUSB-Cが53 mm（TB4ケーブルの最小曲げ半径は48 mm）、MagSafeが44 mmです。
- 出口：後ろの裾は、出口に近づくほど薄くなります。溝の屋根の上の肉が1.2 mmを切る手前から、溝は上まで抜けた垂直の切り込み（ゲート）になります。
  - 斜めに裾を切り裂いたような穴にならず、2本の平行な切り込みとして見えます。
  - 出口の近くでは、ケーブルを上から落とし込めます。
- 天井は45°の屋根形なので、橋渡しなしで刷れます。
- 端面には、プラグの置き場のくぼみがあります（USB-C 7.8×13.4 mm、MagSafe 4.9×13.6 mm、深さ2 mm、端面と同じ7°の傾き）。Macから抜いたプラグを、挿すときと同じ縦向きで差しておけます。くぼみの天井から外の面までは、面取りの際でも1.6 mm以上あります。
- 磁石は使っていません。MacBookのふたの開閉センサーは磁石に反応するためです。

## 5. 熱

- 実測はありません。以下は計算と公開データからの見積もりです。
- Notebookcheckの測定では、M5のAirは負荷をかけるとヒンジ側の半分が40〜44 °C、手前側が30〜33 °Cになります。
- ヒンジを下にすると、熱い側がドックの中に入ります。それでも次の工夫で影響を小さくしました。
  - Macに触れるのは、V溝のフェルトがヒンジ側の角に当たる2本の線だけです。
  - 中央の84 mmは、溝の壁をMacから6.35 mm離しています。
  - 峰の部分でも、パッド以外はMacから2.1 mm離れています。
  - Macの正面（平らな部分）のうち、3 mm以内にPETGがあるのは4.4%だけです。2版はフェルトの壁が8%を覆っていました。
- 自然対流の理屈では、熱い側が下にあるほうが冷えやすくなります（下のほうが空気の流れが速い）。ただし放射もあるので差は小さく、ヒンジ上との差は±2 °Cの範囲と見ています。
- 印刷したPETGやPLAは熱をほとんど通しません（約0.2 W/m·K）。ドックがMacを冷やすことはないので、冷却効果はうたいません。
- 材料の余裕：PETGの荷重たわみ温度は62〜68 °Cです。夏（室温30〜35 °C）の負荷時にヒンジ側が45〜53 °Cになっても、10〜20 °Cの余裕があります。PLAは55 °C前後で柔らかくなるので、荷重のかかる部分とMacに近い部分には使っていません（バッジはMacから14 mm）。
- M5のAirは、ふたを開けたままでも外部ディスプレイを2台つなげます。重い処理を長く続けるときは、開けて使う選択肢もあります。

## 6. Clawdのバッジと蓄光

- ピクセル配置は、Claude Code CLI（npm `@anthropic-ai/claude-code` 2.0.77）の起動画面のブロック文字を、そのまま2×2の区画に分けたものです。1ピクセルは幅1.75 mm×高さ3.5 mmで、全体は28×17.5 mmです。
- 置き場所は、中央の低い部分の45°の正面です。座った目線に対して正面を向き、Macのヒンジのすぐ手前にあります。
  - 正面の幅は24.5 mmで、上下に3.3 mmずつ余白を残しました（1ピクセル2 mmの32×20 mmでは余白が2 mmしかなく、峰の丸みと裾の丸みの間に押し込まれて見えました）。
  - 650 mm離れた席から見て、1ピクセルは視角9分あり、十分に読めます。
- バッジは厚さ3 mmで、表から2 mmが蓄光PLA、奥の1 mmが白PLAです。
  - 蓄光の明るさは、厚さ2 mmくらいまで増え、それ以上はほとんど変わりません（CNC Kitchenの測定）。
  - 奥の白が光を前へ返します。
  - 中まで充填100%で刷ります。充填のすき間があると蓄光の厚みが足りず、光り方にむらが出るためです。
  - 蓄光はオレンジを勧めます。昼に見る時間のほうが長く、昼の見た目がClawdの色（#D77757）に一番近いからです。夜の明るさを最優先するなら緑です。
- 目は、本体から立ち上がる黒PETGのピン（1.75×3.5 mm）です。バッジの目の穴を通って表に出るので、黒い目になります。
  - 同時に、このピンがバッジを留めています。PLAとPETGはほとんど接着しないので、接着剤ではなく形で留めています。
  - すき間はバッジの側に持たせました。目の穴は片側0.10 mm大きく（`--pin-clr`）、外形は片側0.15 mm小さく（`--badge-clr`）してあります。
  - 本体のくぼみとピンは図面どおりの寸法です。固すぎたり緩すぎたりしても、刷り直すのは5分のバッジだけで済みます。
  - 45°の面から立つピンは、下向きの面が少し垂れて太めに出ます。既定のすき間は、それを見込んだ値です。
  - 外すときは、底の穴（Ø2.5）から押し出します。穴はくぼみの床まで完全に抜けています。
- バッジのくぼみの壁はすべて45°か垂直なので、橋渡しなしで刷れます。
- 蓄光は2時間ほどで最初の1割ほどの明るさになります。それでも暗さに慣れた目には見え、夜にドックの位置の目印になります。

## 7. 材料の分け方

| 部分 | 材料 | 理由 |
|---|---|---|
| 本体（荷重を受ける・Macに近い） | 黒PETG | 荷重たわみ温度62〜68 °C。PLAは45 °Cでクリープする |
| バッジ | 蓄光PLA＋白PLA | 同じPLA同士なので層がくっつく。荷重はかからない |
| Macに触れる部分 | 黒のフェルト | 金属や硬い樹脂を当てない（Appleの寸法図の注意書き：NO METAL CONTACT）。空のドックで見えるので、本体と同じ黒にする |
| 脚 | 平らなゴム脚 | 滑りにくい。くぼみに入れて横にずれないようにする |

## 8. 印刷性

| 項目 | 結果 |
|---|---|
| メッシュ | 本体・バッジ・ゲージとも1つの閉じたソリッド（STLを読み直して確認） |
| スライス | PrusaSlicer 2.7にP2S相当の速度・加速度を設定し、3つともエラーも警告もなし |
| 本体 | 0.16 mm・壁5・ジャイロイド20%で185 g・7時間37分。0.20 mmなら190 g・6時間24分 |
| ゲージ | 24 g・56分（試し片と櫛） |
| バッジ | 1.3 g・4分半（色替えの時間は含まない） |
| 45°より急な下向きの面 | 脚のくぼみの天井（483 mm²）とプラグ置き場の天井（25 mm²、奥行2 mm）だけで、どちらも短い橋渡し。ほかはロフトのメッシュの面が最大50°になる程度。サポートは不要 |

- 3MFには、Bambu Studioが読むオブジェクトごとの設定（`Metadata/model_settings.config`）を入れてあります。
  - 本体：層の高さ0.16 mm、壁ループ5、充填20%のジャイロイド、継ぎ目は奥
  - ゲージ：本体と同じ設定で、層の高さはプロセスの設定のまま（0.20 mm）
  - バッジ：充填100%、パーツごとのフィラメント（蓄光＝1、白＝2）
  - Bambu Studioのソース（`bbs_3mf.cpp` と `PrintConfig.cpp`）で、他社製3MFでもこのファイルを読むこと、キーと値の名前が正しいことを確かめてあります。
- 層を0.16 mmにしたのは、20°前後のゆるい裾（座った目線で見える面の約14%）の段を細かくするためです。0.20 mmでは段の幅が0.55 mm、0.16 mmでは0.44 mmになります。
- 継ぎ目を奥に集めると、前半分の島は継ぎ目が溝の内側に、後ろ半分の島は後ろの面に並びます。どちらも正面からは見えません。何も指定しないと、継ぎ目の多くがClawdのくぼみの角に並びました（デザインのレビューがG-codeで確認）。
- 前の版でPrusaSlicerが出していた「ベッドへの付着が弱い」という警告は、ケーブルの溝を裾の先から内側へ移したあとは出なくなりました。
- 高さ6.1 mmより上では、前後の2つの島に分かれて刷られます。溝をまたぐ移動で糸を引くことがあるので、フェルトを貼る前に溝の中を掃除してください。
- ゲージは、本体を刷り直さないと直せないもの（Macのはまり具合）だけを試します。
  - はじめは、バッジのはまり具合とケーブルの入口を試す小片も入れていましたが、それだけで60 g・3時間41分になりました。
  - そこで、バッジは自分の側にすき間を持たせ、入口は削って広げられることにして、小片をやめました。

## 9. まだ確かめていないこと

- 実際の印刷と、実物のMacBook Air 13（M5）でのはまり具合。とくにヒンジ側の角の形。
- 実物のフェルトの厚さ（±0.2 mm）と、45°の面に貼ったときの粘着の持ち。
- 倒れにくさ・持ち上げ・排熱の実測（READMEの「実物での確かめ方」）。たわみの値は、印刷した構造を近似した有限要素法の計算です。
- Bambu Studioで開いた結果。コンテナにインストールできなかったため、ソースコード（`bbs_3mf.cpp`）を読んで確認しました。他社製3MFの「1オブジェクト＋複数コンポーネント」は、1つのオブジェクトの複数パーツとして読み込まれます。

## 10. レビューで直したこと

モデルができたあと、観点ごとに別のレビュアーが、実際にモデルを作り直したり、測ったり、スライスしたり、有限要素法で計算したりして確かめました。直した主な点は次のとおりです。

| 指摘 | 直し方 |
|---|---|
| ゲージの櫛の溝が重なっていて、歯がなかった | 溝の間隔をパッドのくぼみ込みで決め直し、歯は最低4 mm。`check_fit.py` で歯の厚さを検査する |
| 櫛の溝の前がふさがっていて、Macの縁に沿って滑らせられなかった | 前後と上に抜けた溝にし、底でつなぐ |
| `--v-offset` を0.6 mm以上にすると、パッドの台が壁から浮いた | 台を壁の中まで根を張る形にし、ソリッドが1つであることを毎回確かめる |
| `--mac-t` で厚さを変えても、溝の壁が動かなかった | 壁の位置をMacからのすき間で決める。無理な組み合わせはエラーで止める |
| Macの座る高さの計算で、フェルトのへたりを縦に足していた | 斜面に垂直なへたりとして√2倍で扱う |
| 45°の面から立つ目のピンがきつすぎた | すき間を片側0.10 mmにし、すき間をバッジの側に移した |
| バッジの中が充填のすき間になると、光り方にむらが出る | 3MFに充填100%を入れた |
| ケーブルの溝とプラグ置き場で裾の先が薄い刃になり、PrusaSlicerが付着の警告を出した | 溝を内側（23 mmと32 mm）へ移した |
| パッドのくぼみの天井が水平の張り出しだった | 天井を45°にした |
| 押し出し用の穴の上が、くぼみの床で一部ふさがっていた | 穴を床の最も高い所まで通す |
| パッドの台の縁が角ばっていて、端の面取りとぶつかっていた | 台の上下をS字の斜面にし、傾けた端面と面取りから離した |
| 傾けて抜くと、パッドのフェルトの摩擦でドックが浮く | フェルトのまま、READMEに真上に抜くことと5°傾けた確かめ方を書き、滑るテープの版（`--liner`）を用意した |
| Macの角がV溝のフェルトの縁に載っていた | フェルトのくぼみを斜面の上へずらし、角が縁から2.5 mm内側に載るようにした |
| 検査が本当は何も確かめていない項目があった | `check_fit.py` を作り直し、落ちた検査の名前を出して止まるようにした。作り直しのオプションをそのまま受け取る |
| 中央と峰のつなぎ目で、峰の線が0.4 mmへこんでいた | ロフトを19断面にし、補間式との差を `check_fit.py` で測る（0.001 mm） |
| 座った目線で、「太すぎる」1版の86%の量感があった | 峰を60 mmに下げ、端面を7°傾け、Clawdを一回り小さくした（量感は約9%減） |
| ケーブルの出口が、裾を斜めに切り裂いた穴になっていた | 肉が薄くなる手前から、垂直の切り込み（ゲート）にした |
| ケーブル用の切り欠きが、使わない左端にもあった | ポートのある右端だけにし、左端は富士山形の断面のまま見せる |
| 倒れにくさを、脚の外縁を支点にして計算していた（4.2 N） | 脚の中心で浮き始める力（3.7 N）と、倒れる力（4.0 N）を分けて出す。READMEの確かめ方の基準も直した |
| V溝の下（3.4 mm）が蝶番になり、Macの重さでパッドのすき間が0.2 mm閉じた | V溝ごと1.5 mm上げて4.9 mmにし、残りはパッドの位置で打ち消した |
| 指定のない継ぎ目がClawdのくぼみの角に並び、ゆるい裾に段が出る | 継ぎ目を奥に、本体の層を0.16 mmにする設定を3MFに入れた |
| 製品イメージが、濃い色のMacと低いカメラでドックを軽く見せていた | シルバーのMacで、座った目線の画像を加えた。本物の折れ目が消えないよう、なめらかにする角度を12°にした |
| フェルトの色と蓄光の色が決まっていなかった | 黒のフェルト、オレンジの蓄光を勧める |
