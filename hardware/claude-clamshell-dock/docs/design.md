# 設計ノート：寸法の決め方と検証結果

数値の正本は `src/clamshell_dock.py` の `P` クラスです。調査の内容は[リサーチ](research.md)にあります。

## 0. 最初の版から変えたこと

最初の版（2026-09-28）には、次の3つの問題がありました。
- ファイルが多すぎた。36ファイルのうち、刷るのは3つだけでした。
- 本体が太すぎた。
- 排熱は、差す向きしか考えていませんでした。

そこで、MacBook Air 13（M5）専用にして作り直しました。

| | 最初の版 | この版 |
|---|---|---|
| 刷るファイル | 3（全体は3MF 10・STL 19・STEP 7） | 2（本体とロゴ） |
| 外形 | 200×116×46 mm | 180×104×34 mm |
| 本体の断面積 | 約4,000 mm² | 770 mm² |
| 上端の幅 | 約105 mm | 23.6 mm |
| PLA／時間 | 252 g／約4時間 | 95 g／約2時間 |
| Macに触れるもの | 印刷したTPUライナー（機種別5種） | 貼るフェルト2 mm |
| 倒れにくさ（Air 13、同じ条件） | 24.3°、3.0 N | 24.7°、2.9 N |
| 排熱の影響（概算） | 約+0.8 °C | 約+0.4 °C |

なくしたものと、その代わりは次のとおりです。
- **TPUライナー、試し片、TPU脚**：フェルトと市販のゴム脚にしました。TPUは外部スプールで2〜3時間かかるうえ、はまり具合の調整も要りました。
- **底のケーブル溝とグロメット**：底板を薄くしたので、溝を入れる厚みがありません。ケーブルが落ちるのが気になる場合は、市販のケーブルクリップを背面に貼ってください。
- **STL・STEP・ロゴなし本体・単色ロゴ**：同じ形の重複でした。ロゴなしの本体は `--no-logo` で作れます。

## 1. 形と寸法

| 項目 | 値 | 理由 |
|---|---|---|
| 長さ | 180 mm | Air 13（幅304.1 mm）の左右が62 mmずつはみ出す。側面のポートと四隅のゴム足はドックに掛からない |
| 奥行 | 104 mm | 倒れる方向の幅。倒れにくさはここでほぼ決まる（次節） |
| 高さ | 34 mm（ゴム脚込み36 mm） | Macの下端29 mmを支え、正面にロゴ（高さ20 mm）の入る平らな面を残す |
| スロット幅 | 15.6 mm | Air 13の厚さ11.3 mm＋フェルト2 mm×2＋すき間0.3 mm |
| 壁 | 上端4 mm、側面の勾配8° | 薄いほど見た目が軽く、熱も外へ抜けやすい。上端は丸めてある |
| 底板 | 厚さ3〜5 mm、角R18 | 広さで倒れにくさを出し、厚みは最小限にした |
| スロットの床 | 厚さ3 mm | 床のフェルトの上にMacが立つ。Macの下端は机から7 mm |

断面は「薄く広い底板」と「細い立ち上がり」を、R5の曲面でつないだ形です。

## 2. 倒れにくさ

倒れにくさを決めるのは、底の幅とMacの重心の高さです。ドックの重さはほとんど効きません。Air 13（1.24 kg）は、このドック（0.10 kg）の12倍重いためです。最初の版が太かったのは、倒れにくさを本体の大きさで稼ごうとしたからでした。

計算は次の条件で行いました。
- Macとドックを1つの剛体とみなし、静的に計算する。
- 支点は、ゴム脚の外側の縁（中心から49 mm）にする。ドックはここで最初に傾き始める。底板の縁はそこから2.2 mm外にある。
- ドックの重さは0.10 kg。内訳は、PLA 95 g（壁3・充填15%のスライス結果）とフェルト・脚・ロゴ。

| 機種 | 転倒角 | Macの上端を横から押して傾き始める力 |
|---|---|---|
| **MacBook Air 13（M2〜M5）** | **24.7°** | **2.9 N** |
| MacBook Air 15 | 22.4° | 3.2 N |
| MacBook Neo | 25.5° | 3.0 N |
| MacBook Pro 14 / 13 | 23.7° | 3.6 N |
| MacBook Pro 16 | 21.3° | 4.3 N |

（他の機種の行は `--model` で作ったときの値です。スロット幅以外は同じです。）

最初の版では、支点を本体の縁にしていました。実際には、ドックは内側にある脚で先に傾き始めます。同じ条件（脚の縁が支点）で計算し直すと、最初の版は24.3°・3.0 Nでした。重さ4割でほぼ同じ倒れにくさです。

参考として、BookArc（奥行91.4 mm、158 g）にAir 13を立てた場合を試算しました。支点は本体の縁で、スロットの床の高さは30 mmと仮定しています。結果は20°・2.6 Nです。この版を同じ条件（本体の縁が支点）で計算すると、25.6°・3.0 Nです。

## 3. フェルト

- 貼るのは、2 mmの粘着フェルトを3本です。壁用が26×168 mmを2本、床用が15×168 mmを1本です。ダイソーの「切って使えるフェルトシート 裏面テープ付」（30×21 cm）1枚から取れます。
- フェルトとMacの間には、片側0.15 mmのすき間を残しました。フェルトで挟んで固定するほうがぐらつきは減りますが、次の問題が出ます。
  - 2 mmのフェルトを15%押しつぶすと、面圧は数kPaから10 kPa程度になります。壁1面のフェルトは約4,400 mm²あるので、合わせて数十Nで挟むことになります。
  - フェルトと金属の摩擦係数を0.3とすると、Macを抜くときに10〜25 N程度の抵抗が出ます。0.1 kgのドック（約1 N）は持ち上がってしまいます。
- すき間が両側で計0.3 mmあると、Macはフェルトの高さ26 mmの範囲で約0.7°傾けます。Macの上端（215 mm）では約2.5 mm動く計算です。
- 印刷の誤差（スロットは0.1 mmほど狭く出やすい）と、フェルトの厚さのばらつきで、はまり具合は変わります。緩い場合はフェルトの下にマスキングテープ（約0.1 mm）を足します。きつい方向は直しにくいので、少し緩めに設計しました。

## 4. 排熱

### 差す向き
- **ヒンジを上にします**。Apple Silicon搭載のMacBookは、SoCがヒンジ寄りにあります。こうすると、ドックが覆うのは反対側の、一番温度の低い縁になります。
- Airはファンレスで、熱は主に底面と天板から逃げます。
- MacBook Pro 14/16は、底面の左右から吸気し、ヒンジ下の背面から排気します。ヒンジを下にすると排気口がスロットに入るので、避けてください。
- 縦置きは、机に寝かせるより両面が空気に触れるので、それだけで冷えやすくなります。

### ドックが覆う面積と、その影響（概算）
ドックはMacの各面の下端29 mm×180 mmを覆います。これは片面の8.0%です（最初の版は約9.5%）。

覆われた部分から逃げる熱を、厚さ方向の熱抵抗を足し合わせて見積もりました。

| | Macの表面から室内までの熱の逃げやすさ |
|---|---|
| 覆われていない面（自然対流＋放射） | 約8.6 W/m²K |
| 最初の版：空気層7 mm＋PLAの壁40 mm以上 | 約1.1 W/m²K |
| この版：フェルト2 mm＋PLAの壁4〜8 mm | 約4.2 W/m²K |

最初の版は、厚いPLAの壁がほぼ断熱材になっていました。この版は壁が薄いので、覆われた部分からも、露出した面の半分ほどの熱が逃げます。

計算に使った仮定は次のとおりです。
- Airが負荷をかけ続けたときの発熱は約12 W。
- 覆われた縁は、室温より8 K高い。
- Mac全体は、室温より平均13 K高い。
- 充填15%の部分の熱伝導率は0.06 W/mK（セル内の放射を含む）。

この仮定で、ドックのせいで逃げにくくなる熱と、筐体の温度上昇は次のとおりです。

| | 逃げにくくなる熱 | 筐体の温度上昇 |
|---|---|---|
| 最初の版 | 0.75 W | 約+0.8 °C |
| この版 | 0.36 W | 約+0.4 °C |
| この版でヒンジを下にした場合（覆う縁が室温＋20 Kと仮定） | 0.91 W | 約+1.0 °C。SoC付近はさらに上がる |

どれも計算上の目安で、実測ではありません。それでも、差す向きのほうがドックの形より効くことは分かります。

### 通気穴をやめた理由
最初は、スロットの床に通気穴を開ける予定でした。しかし、スロットをフェルト込みでMacの厚さぎりぎりにしたので、Macの周りに空気の通り道が残りません。穴を開けても空気は流れないため、やめました。

### PLAで大丈夫か
PLAの荷重たわみ温度は約57 °Cです。負荷をかけたMacBookの底面は、16インチProで約43 °C、Airの縁はそれより低い温度です。スロットの床にかかるのは、Macの重さ12 Nだけです。夏の締め切った部屋や直射日光の当たる場所に置く場合は、PETGで刷ってください。

## 5. Clawdロゴ

- ピクセル配置は、Claude Code CLI（npm `@anthropic-ai/claude-code` 2.0.77 の `cli.js`）の起動画面のブロック文字 `▐▛███▜▌ / ▝▜█████▛▘ / ▘▘ ▝▝` を、2×2の区画に分解したものです。色も同じテーマ値で、本体はrgb(215,119,87)、目はrgb(0,0,0)です。1ピクセルは幅1：高さ2で、全体は16u×10uです。
- u = 2 mmにして、32×20 mmにしました。立ち上がりの正面の平らな部分（高さ約23 mm）の中央に置いています。
- ロゴは別に、見える面を下にして刷り、正面のくぼみにはめ込みます。縦の面に直接多色で刷ると、ロゴの高さ分ずっと色替えが起きて100回を超えるためです。この方法だと、色替えは最初の3層（目の0.6 mm）だけで済みます。
- くぼみはロゴより片側0.2 mm大きくしてあります。くぼみの天井は、奥側を45°×1.2 mm面取りしました。橋渡しにならず、残る張り出しは0.8 mmだけです。

## 6. 印刷性

| 項目 | 結果 |
|---|---|
| メッシュ | 本体とロゴは閉じたソリッド（STLを読み直して確認） |
| 干渉 | ロゴとくぼみは0 mm³。MacはPLAにもフェルトにも食い込まない |
| スライス | PrusaSlicer 2.7にP2Sの「0.20mm Standard」相当の速度・加速度を設定し、2ファイルともエラーなし |
| 張り出し | ロゴのくぼみの天井だけ（高さ23 mmと31 mmの外周。奥行0.8 mm）。サポートは不要 |
| 橋渡し | 底板の内部のソリッド層（スパース充填の上）だけ。外に見える橋渡しはない |

| 印刷物 | フィラメント | 時間（概算） |
|---|---|---|
| 本体（PLA、壁3・充填15%グリッド） | 95 g | 約2時間 |
| ロゴ（2色、色替えの時間は含まない） | 1.1 g | 約3分 |

時間はPrusaSlicerの見積もりで、Bambu Studioの見積もりとは食い違うことがあります。

角の丸めにも制約があります。立ち上がりの端の縦の角をR2にすると、上端の丸めとぶつかる部分でメッシュにすき間ができました。そのためR1.5にしています。

## 7. まだ確かめていないこと

- 実際の印刷と、実物のMacBook Air 13（M5）でのはまり具合。この作業環境にはプリンターもMacもありません。
- 実物のフェルトの厚さ。2 mmから±0.2 mmずれると、片側のすき間は「0.05 mm押しつぶす」から「0.35 mm空く」までの範囲で変わります。
- 排熱の実測。上の数字は、仮定を置いた熱抵抗の計算です。
- Bambu Studioで開いた結果。コンテナにインストールできなかったため、ソースコード（`bbs_3mf.cpp`）を読んで確認しました。他社製3MFの「1オブジェクト＋複数コンポーネント」は、1つのオブジェクトの複数パーツとして読み込まれます。
