# Claude Code クラムシェルドック（Bambu Lab P2S用）

![MacBook Air 13を立てたところ](images/hero.jpg)

MacBookを閉じたまま（クラムシェルモード）立てておく、縦置きのドックです。正面にはClaude Codeのマスコット「Clawd」をはめ込みます。MacBook Air 13（M5）に合わせてあり、Bambu Lab P2Sでサポートなしで刷れます。

> **正直なお断り**：この環境にはプリンターも実物のMacBookもないため、試し刷りと実機での装着はしていません。確かめたのは、形状（部品同士の干渉、Macとの当たり方）、スライス、倒れにくさと排熱の計算までです。

![ドック本体](images/dock.jpg)

## 用意するもの

| | もの | 目安 |
|---|---|---|
| 印刷 | `print/1_body_PLA.3mf`（本体） | PLA 95 g、約2時間 |
| 印刷 | `print/2_logo_clawd.3mf`（ロゴ） | PLA 1 g、数分（オレンジと黒） |
| 購入 | 粘着付きフェルト 厚さ2 mm（ダイソー「切って使えるフェルトシート 裏面テープ付」30×21 cmなど） | 1枚 |
| 購入 | 貼るゴム脚 直径10〜12 mm・高さ2 mm前後 | 4個 |

印刷時間とフィラメントの量は、PrusaSlicerをP2S相当に設定した概算です。

## 印刷（Bambu Studio、P2S、0.4 mmノズル）

**本体**
1. `1_body_PLA.3mf` を開きます。「Bambu Lab製ではない3MF」という通知が出ますが、そのままで大丈夫です。
2. プロセスは **0.20mm Standard @BBL P2S** を選び、壁ループを **3**、充填を **15%** にします。
3. サポートはなしです。プレートはテクスチャPEIのままにします。

**ロゴ**
1. `2_logo_clawd.3mf` を開きます。1つのオブジェクトに `clawd_orange` と `clawd_eyes_black` の2パーツが入っています。
2. パーツごとに、オレンジと黒のフィラメントを割り当てます。
3. 見える面を下にして刷る向きで入っています。表面はテクスチャPEIのマットな仕上がりになります。

AMSがない場合は、`clawd_eyes_black` を削除してオレンジだけで刷ります。目の部分は深さ0.6 mmのくぼみになるので、黒の油性ペンで塗ります。

色は、ClawdがBambu PLA Matteの **Terracotta** です。公式色 #D77757 に一番近い色です。本体はIvory White、目はCharcoalが合います。

## 組み立て

1. **フェルトを切る**：シートから次の3本を切り出します。シートの裏は方眼になっています。
   - 壁用：幅26 mm×長さ168 mm を2本
   - 底用：幅15 mm×長さ168 mm を1本
2. **仮合わせ**：裏紙を付けたままのフェルトをスロットの両壁と底に置き、Macを差してみます。
   - 裏紙のぶん、本番より少しきつくなります。
   - それでも揺れる場合は、片側の壁にマスキングテープを1〜2枚貼ってから、フェルトを貼ります。
3. **フェルトを貼る**：底、前の壁、後ろの壁の順に貼ります。壁用は底のフェルトの上から始めます。定規などで押さえて貼ります。
4. **ゴム脚を貼る**：底面の四隅に貼ります。脚の中心は、前後の縁から9 mm、左右の端から12 mmの位置です。脚を縁に寄せるほど、倒れにくくなります。
5. **ロゴをはめる**：正面のくぼみに押し込むと、面一になります。緩いときは、接着剤を少しだけ付けます。

## 使い方

- **ヒンジを上**にして差します。天板（Appleのマーク）を手前に向けると、ポートは左上に来ます。
- ヒンジを上にするのは、熱を出すSoCがヒンジ寄りにあるためです。ドックが覆うのは、その反対側で一番温度の低い縁になります。
- クラムシェルモードでは、電源と外部ディスプレイ、外部キーボード・マウスが必要です（[Apple](https://support.apple.com/en-us/102501)）。
- Macを抜いたときにケーブルが机の裏へ落ちるのが気になる場合は、市販のケーブルクリップをドックの背面に貼ってください。

## 寸法

![寸法図](images/drawing.png)

本体は180×104×34 mmです。ゴム脚を含めると高さ36 mmになります。

スロット幅は15.6 mmです。内訳は、Airの厚さ11.3 mm、両側のフェルト2 mm×2、すき間0.3 mmです。

寸法の決め方、倒れにくさ、排熱の見積もりは[設計ノート](docs/design.md)にあります。市販品と作例の調査は[リサーチ](docs/research.md)にあります。

## 検証したこと

`src/check_fit.py` で確かめた内容です。
- 本体とロゴは、閉じたソリッドです。
- ロゴとくぼみの干渉は0 mm³です。
- MacはPLAにもフェルトにも食い込みません。フェルトとのすき間は片側0.15 mmです。
- Macを立てた状態で、24.7°まで傾けても倒れません。Macの上端を横から押すと、約2.9 N（約300 gの力）でドックが脚の外側を支点に傾き始めます。

PrusaSlicer 2.7にP2S相当の設定をして、2つのファイルをスライスしました。サポートは不要です。張り出しは、ロゴのくぼみの天井（奥行0.8 mm）だけです。

確かめていないことは次の3つです。
- 実際の印刷と、実機への装着
- 実物のフェルトの厚さ。2 mmからずれると、はまり具合が変わります。
- Bambu Studioで開いた結果。Bambu Studioのソースコードを読んで、「1オブジェクト＋複数パーツ」として読み込まれることだけを確認しました。

## ほかの機種で作る

```sh
cd src
pip install -r requirements.txt
python3 clamshell_dock.py --model pro14   # air13 / air15 / neo / pro14 / pro16
python3 check_fit.py --model pro14
```

変わるのはスロットの幅だけです。フェルトの厚さを変えたい場合は `--felt 1.0` のように指定します。寸法はすべて `src/clamshell_dock.py` の `P` クラスにあります（build123d製）。

## ロゴと商標

- Clawdのピクセル配置は、Claude Code CLI（npm `@anthropic-ai/claude-code` 2.0.77）の起動画面の描画データをそのまま使いました。色も同じテーマ値の rgb(215,119,87) です。
- Claude、Claude Code、ClawdはAnthropicの商標です。ロゴ部分は個人で楽しむためのファン作品で、Anthropicの公式製品ではありません。
- 販売したり、MakerWorldなどで公開したりする場合は、`python3 clamshell_dock.py --no-logo` でくぼみのない本体を作るか、Anthropicの商標ガイドラインを確認してください。
- それ以外のモデルとスクリプトは、リポジトリのMITライセンスに従います。
